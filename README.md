# ASPA（Arknights Stronghold Protocol Assistant）

《明日方舟》「卫戍协议·规程」准备界面的只读速查工具：识别本局核心/附加盟约的禁用状态，再按等级列出预设名单里仍然可用的叠层干员。

## 功能

- **只读识别**：只截取游戏客户区，不发送鼠标/键盘、不注入、不读内存。
- **叠层手名单**：在编辑器里勾选要关注的叠层干员，保存为预设名单。
- **按等级展示剩余**：识别后只显示名单中没有被 ban 的叠层手，按 Ⅰ～Ⅵ 分组。
- **手动排除**：自动推断有遗漏时，点「排除」手动去掉本局被 ban 的干员。
- **自动更新**：检查 GitHub Releases，下载后重启替换。
- **开箱即用**：发布包自带 Python 与 .NET 运行时，无需安装 Python/.NET。

## 如何使用

1. 打开 [Releases](https://github.com/Qiiamx/ArknightsStrongholdProtocolAssistant/releases/latest)，下载 `ASPA-win-x64.zip`。
2. 解压到一个可写目录（保留 `_internal` 和 `wincap.exe`，不要只拿 exe）。
3. 双击 `ASPA.exe`，侧栏会自动贴到明日方舟窗口右侧。
4. 点 **「编辑叠层手」**，勾选你关心的叠层干员，保存。
5. 在游戏里停在「确认本局信息」页，点侧栏 **「截图识别」**。
6. 侧栏会按等级显示名单中剩余的叠层手；点 **「排除」** 可手动修正。
7. 游戏移动时侧栏跟随；拖动标题栏可自由摆放，点 **「贴边」** 恢复跟随。
8. 有新版本时点 **「更新」**，或启动后等待自动检查。

> “剩余”默认按识别到的盟约和全局可用性规则推断，不是读取禁用干员头像。游戏窗口最小化时无法截图。
