# ASPA（Arknights Stronghold Protocol Assistant）

《明日方舟》「卫戍协议·规程」准备界面的只读速查工具：贴在游戏窗口右侧，读取本局核心/附加盟约的禁用/启用状态、敌方领袖和特训敌人，并按预设给出阵容与大小盟约推荐。

## 功能

- **只读识别**：只截取游戏客户区，不发送鼠标/键盘、不注入、不读内存。
- **准备界面速查**：识别核心盟约、附加盟约、敌方领袖和 9 类特训敌人；支持两组核心布局。
- **预设推荐**：按预设 JSON 对阵容排序，显示主/副盟约、理由和警告。
- **常驻侧栏**：自动贴住游戏右侧并跟随移动，侧栏内「截图识别」按钮直接出结果。
- **阵容/赋分编辑器**：可视化编辑阵容、盟约目标、干员、敌人词条赋分和全局权重。
- **自动更新**：检查 GitHub Releases，下载后重启替换。
- **开箱即用**：发布包自带 Python 与 .NET 运行时，无需安装 Python/.NET。

## 如何使用

1. 打开 [Releases](https://github.com/Qiiamx/ArknightsStrongholdProtocolAssistant/releases/latest)，下载 `ASPA-win-x64.zip`。
2. 解压到一个可写目录（保留 `_internal` 和 `wincap.exe`，不要只拿 exe）。
3. 双击 `ASPA.exe`，侧栏会自动贴到明日方舟窗口右侧。
4. 在游戏里停在「确认本局信息」页，点侧栏 **「截图识别」**。
5. 查看前 3 套推荐；点 **「编辑阵容」** 调整阵容和赋分，保存后自动重算。
6. 游戏移动时侧栏跟随；拖动标题栏可自由摆放，点 **「贴边」** 恢复跟随。
7. 有新版本时点 **「更新」**，或启动后等待自动检查。

> 游戏窗口最小化时无法截图；工具不会自动恢复窗口或发送输入。
