# ASPA（Arknights Stronghold Protocol Assistant）

《明日方舟》「卫戍协议·规程」准备界面的只读速查工具：识别本局核心/附加盟约的禁用状态，再按等级展示预设名单里仍然可用的叠层干员。

## 功能

- **只读识别**：只截取游戏客户区，不发送鼠标/键盘、不注入、不读内存。
- **盟约勾选**：核心/附加盟约以勾选形式展示，识别结果可手动修正；截图失败也能完全手动操作。
- **叠层手名单**：在编辑器里勾选要关注的叠层干员，并可按需修改每个干员拥有的盟约。
- **按等级展示**：按 Ⅰ～Ⅵ 显示剩余叠层手，每个干员只显示等级和勾选框，不显示盟约。
- **盟约筛选与组合**：按盟约筛选干员；勾选的干员常驻显示，顶部实时汇总已选组合，如 `3精准 3奥数 3莱塔尼亚`。
- **持久设置**：「设置」里可填更新代理；配置保存在用户目录，版本更新不会覆盖。
- **自动更新**：检查 GitHub Releases，显示下载进度，下载后重启替换。
- **开箱即用**：发布包自带 Python 与 .NET 运行时，无需安装 Python/.NET。

## 如何使用

1. 打开 [Releases](https://github.com/Qiiamx/ArknightsStrongholdProtocolAssistant/releases/latest)，下载 `ASPA-win-x64.zip`。
2. 解压到一个可写目录（保留 `_internal` 和 `wincap.exe`，不要只拿 exe）。
3. 双击 `ASPA.exe`，侧栏会自动贴到明日方舟窗口右侧。
4. 点 **「设置」** 维护叠层手名单；上半部分可填写更新代理（留空为直连）。
5. 游戏停在「确认本局信息」页时点 **「截图识别」**；没有截图也可以直接勾选上方盟约。
6. 点 **「筛选盟约」** 选择要查看的盟约（默认不选任何盟约，因此不显示干员）。
7. 勾选需要的干员；已勾选干员会一直保留，上方显示组合结果。
8. 有新版本时点 **「更新」**，或启动后等待自动检查；下载时会显示百分比。

> 设置保存在 `%APPDATA%\SPAQuickLook\settings.json`，更新不会覆盖。截图只用于识别；编辑、盟约调整、筛选和更新都不需要打开游戏客户端。
